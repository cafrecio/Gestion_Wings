Qué mirar en una prueba

  1. ¿La pantalla resuelve el trabajo de quien la usa, o solo muestra datos?
  2. ¿El usuario entiende qué pasó? Si no guardó, por qué; si va a perder lo cargado, que se le avise.
  3. ¿Los números coinciden entre pantallas?
  4. ¿El sistema deja hacer algo que el club no puede permitir?
  5. ¿Cada rol hace lo suyo? El dueño no cierra cajas ni se valida a sí mismo.
  6. ¿Qué necesita el club y no tiene dónde anotarse?
