Cómo se obtuvieron estas imágenes

Chrome real, Wings local y datos sintéticos de wings_testing_codex. Escritorio a 1366 px. Para celular se exportó el DOM real de la misma pantalla, conservando los valores y las opciones visibles, y Chrome lo remaquetó dentro de un iframe de 375 px. El login se usó para comprobar que el método no recorta. Wings bloquea incrustar la aplicación viva por sus encabezados de seguridad; por eso el marco muestra la exportación de su HTML real, con tokens neutralizados. No se construyeron maquetas ni se cambiaron vistas o estilos del producto.

Las imágenes originales no se retocaron. En T89, los recuadros rojos pertenecen a esta galería y señalan la zona a revisar; al abrir la imagen se ve la captura sin marcas.
